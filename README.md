# 🚀 MS Portfolio - Personal Dashboard

Welcome to my personal workspace dashboard! This project is a modern, responsive, and aesthetic Bento Grid web portfolio built to showcase active builds, data analytics projects, and live coding stats.

🔗 **Live Website:** [https://msdatahub58.github.io/Portfolio/](https://msdatahub58.github.io/Portfolio/)

---

## 📌 Features & Sections

- **🍱 Bento Grid Layout:** A multi-card dashboard design separating projects, hero stats, music player, and profile links.
- **🎨 Dynamic Aesthetic Theme Switcher:** Real-time color accent shifting (Neon Mint, Vaporwave Lavender, Coral Pink, and Emerald Green) using CSS Custom Properties.
- **🎵 Integrated Lo-Fi Music Player:** Built-in audio player with a spinning vinyl disc animation and custom music controls.
- **📁 Projects Overview:** Quick access to GitHub repositories including portfolio builds and Sales Analysis projects.
- **⚡ Custom Pixel-Art Favicon:** Handcrafted "MS" pixel-art branding integrated into the browser header.
